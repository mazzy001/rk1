# РК 1 — вариант 1

Требуется Python 3.10 или новее. Команды выполняются из папки проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Задание 1

В `task1.py` функция `chunk` берёт срезы списка с шагом `size`.
Последний срез может быть короче остальных. Для пустого списка результат
тоже пустой. `TypeVar` связывает тип элементов входного списка с типом
элементов результата.

В `test_task1.py` проверяются деление без остатка, остаток, размер больше
длины списка, пустой список, размер 1 и недопустимые размеры.

```bash
python -m pytest -q
```

## Задание 2

Гонка находится в `counter += 1`. Эта операция включает чтение значения,
прибавление единицы и запись результата. Если два потока прочитают одно
значение до записи, один из результатов может затереть другой, и одно
увеличение потеряется. В некоторых версиях и сборках Python ошибка может
не проявиться при конкретном запуске, но полагаться на это нельзя.

В `task2.py` общий `threading.Lock` защищает всё увеличение счётчика.
Пока один поток изменяет значение, остальные ждут освобождения блокировки.
После `join` все восемь потоков завершены, поэтому результат равен
`8 * 100_000 = 800000`.

```bash
python task2.py
```

## Задание 3

В `task3.py` модель `Item` содержит название, положительную цену и список
тегов. `Field(gt=0)` задаёт ограничение цены, а `default_factory=list`
создаёт отдельный пустой список тегов для каждого объекта.

Обработчик `POST /items` добавляет целочисленный `id`, начиная с 1,
и возвращает данные товара вместе с ним. Блокировка защищает выдачу id
при одновременных запросах.

```bash
python -m uvicorn task3:app --reload
```

После запуска форму для проверки запросов можно открыть по адресу
http://127.0.0.1:8000/docs.

Пример тела запроса:

```json
{"name": "Тетрадь", "price": 50, "tags": ["учёба"]}
```

Ответ на первый запрос:

```json
{"name": "Тетрадь", "price": 50.0, "tags": ["учёба"], "id": 1}
```

Это учебный обработчик без базы данных. Счётчик хранится в памяти одного
процесса и сбрасывается при перезапуске. Запускать нужно с одним worker.

Использованные справочные материалы:
[поля Pydantic](https://docs.pydantic.dev/latest/concepts/fields/) и
[модели ответа FastAPI](https://fastapi.tiangolo.com/tutorial/response-model/).
